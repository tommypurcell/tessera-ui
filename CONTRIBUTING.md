# Contributing

## Run locally

```shell
pnpm install
pnpm dev
```

Use `pnpm build` before submitting a change. The site is statically exported to `out/`.

## Contribution guidelines

- Keep changes focused and accessible.
- Add or update component metadata alongside its example markup.
- Verify responsive behavior, preview controls, and dark-mode variants where applicable.
- Use concise, sentence-case pull request descriptions.
