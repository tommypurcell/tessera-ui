An original Tessera UI chat bubble set with five genuinely different visual styles — minimal, boxed support widget, colorful team chat, icon-led status feed, and a smartphone-style SMS thread — not the same bubble recolored five times. Each variant's component accepts a `messages` prop so you can drop in your own conversation instead of copying the static example.
