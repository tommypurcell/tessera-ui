Action atoms keep native semantics while making the smallest useful visual decision: hierarchy, hit area, focus, loading, or grouping. Each action supports the shared size scale, visible keyboard focus, readable disabled states, dark mode, and reduced-motion-safe feedback. Compose these into larger controls rather than adding business logic here.
